# Karina & Faizan — Wedding Invitation

## Files
- `index.html` — page structure
- `style.css` — all styling
- `script.js` — animations, countdown (edit `CONFIG` at the top here)
- `robots.txt` — blocks search engines from indexing the site

Anyone with the direct link can open the site normally — no passcode.

## Go live with GitHub Pages (free)

1. Go to **github.com** → **New repository**. Give it any name, e.g.
   `karina-faizan-wedding`. Keep it **Public** (GitHub Pages' free tier
   requires this — search engines still won't index it, thanks to
   `robots.txt` and the noindex tag already in `index.html`).
2. On the new repo's page, click **uploading an existing file** and drag in
   all four files: `index.html`, `style.css`, `script.js`, `robots.txt`.
   Commit the upload.
3. Go to the repo's **Settings → Pages** (left sidebar).
4. Under "Build and deployment" → **Source**, choose **Deploy from a
   branch**. Branch: `main`, folder: `/ (root)`. Click **Save**.
5. Wait about 1–2 minutes, then refresh that Pages settings page — it'll
   show your live URL, something like:
   `https://yourusername.github.io/karina-faizan-wedding/`
6. Open that link to confirm it works, then share it with your guests.

## Making changes later

Any time you want to update text, dates, colors, etc.:
1. Edit the file directly on GitHub (open the file in the repo → pencil/edit
   icon → make changes → **Commit changes**), or edit locally and `git push`.
2. GitHub Pages automatically redeploys within a minute or two — no extra
   steps needed. Just refresh the live link to see the update.
